## Cambio funcional

El punto central es `CatalogRules.save()`, invocado por `AdminRepository.saveItem()` desde `AdminViewModel.save()` y otras rutas existentes. Tras obtener el ID definitivo, comprueba su presencia en `root.items`:

- ID ausente: asigna la hora del guardado mediante el helper existente `now()`, que llama a `Instant.now().toString()`. No usa fechas de estreno, TMDB, orden de lista ni hora de creación del borrador.
- ID existente con campo: copia exactamente su valor original, sin normalizarlo, sustituirlo o volver a generarlo.
- ID existente sin campo: mantiene su ausencia, aunque el candidato proponga una fecha.

Trabaja sobre copias. La validación y escritura atómica originales permanecen vigentes; el repositorio cambia su estado sólo después de una escritura satisfactoria. Una validación fallida, cancelación o escritura fallida no incorpora el registro ni fecha al catálogo persistido. No se generan campos de fecha para temporadas ni episodios. Una sincronización fallida conserva la fecha local original para el reintento.

`CatalogRules.publicCopy()` y `HttpAdminRemote.publish()` ya conservan el campo. No se modifica el esquema ni el Worker ni se consulta producción. Las fichas históricas, incluida la película usada antes de esta corrección, no se completan automáticamente.

## Firmar con el keystore existente

Conservar la clave y el alias usados para la APK instalada. No crear otro keystore ni usar el debug.keystore de otra PC. El certificado histórico documentado para la entrega 0.1.4 tiene SHA-256 `c5125975ac14bcd11ffb402158ba112f0e72c92b87df268b56b77f810cafd49b`; comprobarlo contra la APK que efectivamente se instaló, porque una compilación local puede usar otra clave.

Opción Android Studio: abrir este proyecto separado, **Build → Generate Signed Bundle / APK → APK**, elegir el módulo `admin`, seleccionar el keystore existente y su alias, introducir contraseñas sólo localmente y elegir release. Verificar versión 0.1.5/code 6 y paquete `ar.com.miflix.admin` antes de instalar. No guardar claves ni contraseñas en Git.

Alternativa con Android SDK Build Tools en PowerShell (reemplazar rutas/alias; las contraseñas se solicitan de forma interactiva):

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\build-tools\34.0.0\zipalign.exe" -f -p 4 ".\admin\build\outputs\apk\release\admin-release-unsigned.apk" ".\admin-0.1.5-aligned.apk"
& "$env:LOCALAPPDATA\Android\Sdk\build-tools\34.0.0\apksigner.bat" sign --ks "C:\ruta-privada\keystore-existente.jks" --ks-key-alias "ALIAS_EXISTENTE" --out ".\MiFlix-Admin-Android-0.1.5-firmada.apk" ".\admin-0.1.5-aligned.apk"
& "$env:LOCALAPPDATA\Android\Sdk\build-tools\34.0.0\apksigner.bat" verify --verbose --print-certs ".\MiFlix-Admin-Android-0.1.5-firmada.apk"
```

Comparar el certificado con la APK anterior usando también `apksigner verify --print-certs`. Instalar como actualización, sin desinstalar ni borrar datos. Si Android rechaza la firma, detenerse y recuperar la clave correcta; no cambiar applicationId ni eliminar datos para esquivar el problema.
